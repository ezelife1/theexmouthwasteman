# The Exmouth Waste Man - upload and SEO checks

Extract the full ZIP and double-click index.html to open the website locally. Keep the extracted files together. For GitHub Pages, upload the contents to the publishing root and keep CNAME and .nojekyll. The canonical production address is https://theexmouthwasteman.co.uk/.

The sitemap contains the homepage, seven service pages, a coverage page and a clearance projects page. The custom 404 is excluded.

After deployment, check all sitemap pages return 200 and a missing address returns 404. Check HTTPS, robots.txt, the sitemap and assets/exmouth-waste-man-share.jpg on the public domain. The sharing image should return image/jpeg without authentication; refresh the social preview cache if needed. Submit the sitemap in Google Search Console, inspect the new pages, then track queries, clicks and enquiries. Run PageSpeed Insights against the live site. These live checks have not been completed.
